# Сборка PDF-конспекта

PDF собирается из HTML-вёрстки (`urok-N-konspekt.pdf.html` в папке урока) с общим стилем `style.css`.
Картинки (слайды и кадры из записи) лежат рядом с HTML в папке `kadry/` только на время сборки, в репозиторий не коммитятся.

```bash
cp tools/pdf/style.css <папка-сборки>/        # HTML ссылается на style.css и kadry/*.jpg
node tools/pdf/render.js "$PWD/<папка-сборки>/konspekt.html" "$PWD/raw.pdf" "Урок N · Название для колонтитула"
python3 -I tools/pdf/fix_outline.py raw.pdf <папка-урока>/urok-N-konspekt.pdf "Урок N. Название" <папка-сборки>/konspekt.html
```

- `render.js` печатает A4 через Playwright/Chromium с колонтитулом и **оглавлением по заголовкам** (`outline: true`).
- `fix_outline.py` переписывает оглавление в **вложенные закладки** с чистыми названиями:
  - верхний уровень — обложка, «Что нового», «Структура», разделы `<h2>` в виде «N. Название (таймкод)»;
  - второй уровень — подразделы `<h3>` внутри раздела;
  - PDF открывается с панелью закладок (`/UseOutlines`).
- Чтобы пункт попал в закладки, оформляйте его заголовком `<h2>` (раздел) или `<h3>` (подраздел), а не `<div>`.
