# Конспекты видеоуроков

Репозиторий: https://github.com/alishnik/ai-lessons-notes

Здесь хранятся конспекты видеоуроков: расшифровки, структурированные конспекты, домашние задания и их PDF-версии. Сейчас в репозитории все четыре урока курса о нейросетях для личной жизни и работы (автор — Дмитрий Ятленко): два видеоурока и записи двух онлайн-вебинаров (уроки 3 и 4).

## Структура

Каждый урок лежит в своей папке. Имя папки: `<курс>-urok-<номер>-<тема>` (транслитом). Все файлы внутри начинаются с номера урока: `urok-<N>-…`.

```
.
├── README.md
├── neuroseti-urok-1-podklyuchenie/        # Урок 1. Подключаем нейросети за 5 шагов
│   ├── urok-1-transcript.md               # расшифровка видео
│   ├── urok-1-konspekt.md                 # конспект
│   ├── urok-1-konspekt.pdf                # свёрстанный конспект со слайдами
│   ├── urok-1-dz.md                       # домашнее задание
│   └── urok-1-dz.pdf                      # домашнее задание в PDF
├── neuroseti-urok-2-cifrovoy-dvoynik/     # Урок 2. Цифровой двойник и продвинутые запросы
│   ├── urok-2-transcript.md
│   ├── urok-2-konspekt.md
│   ├── urok-2-konspekt.pdf
│   ├── urok-2-dz.md
│   └── urok-2-dz.pdf
├── neuroseti-urok-3-vebinar-neyropasport/ # Урок 3. Вебинар: нейропаспорт и ИИ-помощники
│   ├── urok-3-transcript.md
│   ├── urok-3-konspekt.md                 # с разделом «Что нового по сравнению с уроками 1–2»
│   └── urok-3-konspekt.pdf                # свёрстанный конспект с кадрами из записи эфира
└── neuroseti-urok-4-vebinar-prodvizhenie/ # Урок 4. Вебинар: продвижение с нейросетями
    ├── urok-4-transcript.md               # ⚠️ первый час без звука — реконструкция по слайдам
    ├── urok-4-konspekt.md                 # с разделом «Что нового по сравнению с уроками 1–3»
    └── urok-4-konspekt.pdf                # свёрстанный конспект со слайдами
```

## Какие файлы есть у урока

| Файл | Что внутри |
|---|---|
| `urok-N-transcript.md` | Полная расшифровка видео. Сделана автоматически (Whisper large-v3-turbo) и вычитана: исправлены явные ошибки распознавания, например названия нейросетей. Текст разбит на разделы с таймкодами вида `## [01:17] …`. В шапке ссылка на видео и его длительность. |
| `urok-N-konspekt.md` | Конспект урока. В шапке ссылка на видео, место урока в курсе и ссылка на расшифровку. Дальше идут главная мысль урока, его структура, разделы с таймкодами, кейсы и шаблоны промптов, упомянутые инструменты, домашнее задание, анонс следующих уроков и «шпаргалка в одну строку». |
| `urok-N-konspekt.pdf` | Свёрстанная версия конспекта со слайдами из лекции, чтобы читать и печатать. С вложенными закладками по разделам (у урока 3; исходная вёрстка — `urok-3-konspekt.pdf.html`). |
| `urok-N-dz.md` | Домашнее задание со страницы урока (sk-ai.ru): шаги, практики, готовые промпты, частые ошибки. В конце сравнение старой и новой версий страницы (`lessonN` и `lessonN_2`). |
| `urok-N-dz.pdf` | Домашнее задание в PDF. |

Файлы ссылаются друг на друга: конспект ведёт на расшифровку, домашнее задание — на конспект.

## Как добавить новый урок

1. Создать папку `<курс>-urok-<N>-<тема>`.
2. Сделать расшифровку видео в `urok-N-transcript.md`: разделы с таймкодами, ссылка на источник в шапке.
3. По расшифровке написать `urok-N-konspekt.md` в той же структуре, что у предыдущих уроков, и сверстать `urok-N-konspekt.pdf` со слайдами. PDF обязательно с вложенными закладками по разделам и подразделам (сборка — `tools/pdf/`, см. [tools/pdf/README.md](tools/pdf/README.md)).
4. Перенести домашнее задание со страницы урока в `urok-N-dz.md` и сделать `urok-N-dz.pdf`.
5. Добавить урок в раздел «Уроки» этого README.
